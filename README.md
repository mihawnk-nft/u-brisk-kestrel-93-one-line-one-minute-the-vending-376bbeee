One pickup line a vending machine would say to a passing human — 67 characters, no setup needed:

> Are you a coil? Because every time you walk by, I get stuck on you.

The joke turns the classic vending-machine mishap — a snack stuck in the coil — into affection: the machine is the one stuck, not the human.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python stdlib, no network, fully deterministic.
